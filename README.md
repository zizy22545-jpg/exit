# Экспортный патруль

Рабочий демонстрационный MVP сервиса предварительного комплаенс-анализа экспортных сделок. Приложение полностью работает в браузере: без backend, платных API и внешних источников данных.

## Возможности

- пошаговая форма параметров сделки;
- пять стран и пять категорий оборудования;
- демонстрационная проверка контрагента с явной маркировкой демо-режима;
- детерминированный rule-based risk engine;
- анимированный экран анализа;
- подробный отчет с картой рисков, факторами внимания и рекомендациями;
- интерактивный чек-лист документов;
- печать или сохранение отчета в PDF средствами браузера;
- адаптивный интерфейс и print-friendly верстка.

> Результат формируется по локальной демонстрационной базе и не является юридическим заключением.

## Установка и локальный запуск

Понадобится Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

Готовые статические файлы будут созданы в папке `dist`. Файлы в корне `dist` можно разместить на любом статическом хостинге; папки `client` и `server` используются для совместимости с Sites.

Для локальной проверки production-сборки:

```bash
npm run preview
```

## Структура проекта

- `components/` — интерфейсные компоненты;
- `data/` — страновые, товарные, платежные и нормативные демо-данные;
- `services/riskEngine.ts` — логика анализа сделки;
- `types/` — TypeScript-типы;
- `app/globals.css` — стили, адаптивность и печатная версия;
- `public/` — логотип и публичные материалы.

Локальные данные отделены от компонентов, поэтому их можно постепенно заменить API или backend без полной переработки интерфейса.

## Как загрузить на GitHub

1. Создайте на GitHub новый пустой репозиторий, например `export-patrol`.
2. Откройте терминал в папке проекта.
3. Выполните команды, заменив адрес репозитория на свой:

```bash
git init
git add .
git commit -m "Первый рабочий MVP"
git branch -M main
git remote add origin https://github.com/USERNAME/export-patrol.git
git push -u origin main
```

## Публикация на GitHub Pages

Файл автоматической публикации уже находится в `.github/workflows/deploy.yml`.

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. Если код еще не отправлен, выполните `git push` в ветку `main`.
5. Откройте вкладку **Actions** и дождитесь завершения процесса **Deploy to GitHub Pages**.
6. Готовая ссылка появится в завершенном процессе и в разделе **Settings → Pages**.

При каждом следующем push в `main` сайт будет автоматически пересобран и опубликован.

## Демо-сценарий

На главной странице нажмите **«Загрузить пример сделки»**. Форма заполнится примером сделки с Китаем, станком, расчетами в CNY и аккредитивом. Пройдите к последнему шагу и запустите проверку.

## Важное ограничение

«Экспортный патруль» — демонстрационный прототип информационно-аналитического сервиса. Он не содержит исчерпывающей или гарантированно актуальной санкционной и правовой информации. Для реальных сделок необходима проверка по актуальным официальным источникам и, при необходимости, консультация специалиста.
